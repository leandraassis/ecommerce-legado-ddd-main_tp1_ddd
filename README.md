# E-commerce legado — atividade de DDD

Aplicação monolítica propositalmente acoplada para uma atividade de refatoração.

Conforme a atividade, o contexto de Pagamento foi extraído do monólito seguindo DDD. Os demais contextos permanecem como no monólito original, sem refatoração (penas o ponto de integração com Pagamento foi ajustado).
